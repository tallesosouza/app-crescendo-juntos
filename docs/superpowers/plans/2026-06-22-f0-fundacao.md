# F0 — Fundação do Projeto · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Estabelecer o monorepo do "Crescendo Juntos" com backend NestJS (Clean Architecture), frontend Angular 22 PWA, e o **schema inteiro do ER** criado no Postgres via Prisma, tudo construível, testável e pronto para deploy.

**Architecture:** Monorepo pnpm workspaces com `backend/` (NestJS 11, camadas domain/application/infrastructure/presentation), `frontend/` (Angular 22 PWA) e `shared/` (contratos de tipo). Postgres local via Docker para dev/teste; AWS RDS em produção. Prisma é o único ponto que conhece o banco.

**Tech Stack:** Node 22 LTS · pnpm 9 · NestJS 11 · Prisma 6 · PostgreSQL 16 · Angular 22 · Jest · TypeScript 5.

## Global Constraints

- **Node:** 22 LTS · **pnpm:** 9 (gerenciador único; nada de npm/yarn nos workspaces).
- **Backend:** NestJS 11, Clean Architecture — domínio **não** importa Prisma/NestJS; Prisma Client vive só em `infrastructure`.
- **Frontend:** Angular 22, **standalone components**, **signals**, **signal-forms** (não reactive forms), **PWA desde o início**.
- **Banco:** PostgreSQL; **schema inteiro do ER** criado já (todas as tabelas). Nomes de tabela/coluna em **snake_case PT-BR** (igual ao ER); enums nativos do Postgres.
- **Sem dados mockados:** toda tela lê da tabela real; catálogos por seed; sem dados → estado vazio.
- **Convite** via tabela `convite` com token. **`permissao.aba`** sem `chat`.
- **TDD** e **verificação real** (rodar/observar) antes de declarar qualquer task concluída. Commits frequentes.
- **Deploy:** backend Render, frontend Vercel, Postgres AWS RDS, auth Supabase.

```ts
import { PrismaClient } from '@prisma/client';

const MUNICIPIOS = [
  { nome: 'Ilhéus', uf: 'BA', codigo_ibge: '2913606' },
  { nome: 'Itabuna', uf: 'BA', codigo_ibge: '2914802' },
  { nome: 'Salvador', uf: 'BA', codigo_ibge: '2927408' },
];

export async function seedMunicipios(prisma: PrismaClient): Promise<number> {
  for (const m of MUNICIPIOS) {
    const existing = await prisma.municipio.findFirst({ where: { codigo_ibge: m.codigo_ibge } });
    if (existing) {
      await prisma.municipio.update({ where: { id: existing.id }, data: m });
    } else {
      await prisma.municipio.create({ data: m });
    }
  }
  return MUNICIPIOS.length;
}

async function main() {
  const prisma = new PrismaClient();
  try {
    const n = await seedMunicipios(prisma);
    console.log(`Seed: ${n} municípios garantidos.`);
  } finally {
    await prisma.$disconnect();
  }
}

if (require.main === module) {
  main();
}
```

> Nota: `codigo_ibge` é `@unique`; usamos `findFirst` + `create/update` para idempotência sem depender de `upsert` por campo não-id.
